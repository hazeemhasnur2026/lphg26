# Arsip

Berkas di folder ini tidak dirujuk satu pun baris kode, tidak ikut dibangun, dan
tidak pernah dikirim ke peramban. Semuanya bahan rujukan saat mengerjakan desain.
Disimpan supaya jejaknya tidak hilang, dipisahkan supaya tidak tercampur dengan
berkas yang dipakai aplikasi.

| Berkas | Isi | Catatan |
|---|---|---|
| `keyvisual-single.pdf` | panduan key visual | dokumen internal perusahaan |
| `simple-guide.pdf` | panduan merek ringkas | dokumen internal perusahaan |
| `logo-60th-horisontal.png` | logo HUT ke-60, mendatar | versi yang dipakai situs ada di `assets/img/logo-60th.png` |
| `logo-60th-vertikal.png` | logo HUT ke-60, tegak | tidak dipakai situs |
| `keyvisual-corner-transparent.png` | ornamen sudut | versi yang dipakai situs ada di `assets/img/keyvisual-corner.png` |
| `referensi-bisnis.png` | rujukan tata letak kartu SBU | dipakai saat menyusun beranda |
| `referensi-tata-letak.jpg` | rujukan tata letak umum | dipakai saat menyusun beranda |
| `referensi-tangkapan-layar.png` | tangkapan layar situs lama | bahan pembanding |

Dua berkas PDF di atas adalah dokumen internal. Repositori ini privat, jadi
sebarannya terbatas pada orang yang diberi akses. Bila suatu saat repositori
dibuka untuk umum, keduanya harus dikeluarkan lebih dulu, dan mengeluarkannya
dari riwayat git menuntut penulisan ulang riwayat, bukan sekadar commit
penghapusan.
